Back-End Semiconductor Mapping

A detailed cross-reference between Pearson BTEC International L3 Engineering Unit 36 (Programmable Logic Controllers) Learning Aims A–D and the IEG Korea Semiconductor Meister High School curriculum — scoped specifically to back-end process and packaging operations, including Die Bonding, Molding, Sawing, Wire Bonding, and Post-Process Testing.

Scope rationale: IEG's primary product strength and ALAT/TAFE SA's semiconductor TVET need centres on back-end process and cleanroom packaging (post-wafer-fab). This mapping therefore prioritises subjects from the IEG Meister High curriculum that directly relate to back-end operations — Die Bonding, Wire Bonding, Molding, Saw/Dicing, Package Testing, and related control/automation systems — and maps these to the BTEC Unit 36 framework where PLC-based control of these automated processes is the core learning vehicle.

Recommended Actions to Close Gaps

🔌 Gap 1 — Industrial Network Protocols

  • Add 1 standalone module: "Industrial Fieldbus for Semiconductor Back-End Lines"
  • Cover EtherCAT (common in Die Bonder / Saw), Profinet (Siemens ecosystems), DeviceNet
  • Practical: configure IEG Testbed PLC to communicate with a simulated vision sensor via EtherCAT
  • Maps to: A2, B2-b

🌡️ Gap 2 — Analog I/O & PID Control

  • Add module: "Analog Control in Back-End Processes" — temperature profiling for mold press, epoxy volume control for die attach
  • Use IEG Oxidation Furnace or Mold Press temperature input as real analog signal source
  • Practical: PLC PID block tuning; compare set vs. actual temperature over cycle
  • Maps to: B2-b, C2

📐 Gap 3 — PLC Software Design Methods

  • Add 2-session module: "Software Design Tools for PLC Systems"
  • Content: Sequential Function Charts (SFC), state diagrams, pseudocode for sequence control
  • Scenario: design a Die Bond → Wire Bond → Mold → Eject sequence using SFC before coding
  • Maps to: C3

🧹 Gap 4 — Cleanroom Design Constraints

  • Add 1-session insert: "Control Panel Design for Cleanroom Environments"
  • Cover: ESD-safe cable selection, sealed enclosure ratings, stainless CDA/UPW fittings, particle-shedding avoidance
  • Reference: actual IEG Cleanroom equipment panel as case study
  • Maps to: C2

📝 Gap 5 — Personal Reflection Rubric (D2)

  • Develop bilingual (KO/EN) self-evaluation form: 4 sections — technical skills, time management, communication, industry-readiness
  • Completed by each learner at end of capstone project
  • Assessed by tutor against BTEC D2 descriptors (Pass / Merit / Distinction)
  • Maps to: D2

📋 Gap 6 — BTEC Evidence Formalisation

  • Existing Meister content is strong but evidence format does not match BTEC requirements
  • Create: BTEC Evidence Tracker (per learner): links each Meister lab activity to a specific BTEC assessment criterion
  • Add tutor observation records + witness statements for Aims B and C practical sessions
  • Maps to: A1, B3, C5, D1
NQF / Credit Equivalence Note

The IEG Meister High curriculum operates at Korean Specification of Qualification Framework (KSQ) Level 3–4, broadly equivalent to BTEC International Level 3 / NQF Level 3. The back-end semiconductor subjects (Years 2–3) align most closely with BTEC L3 Unit 36 at Merit–Distinction boundary due to the industrial depth and equipment complexity involved. Formal credit recognition would require Pearson approval of an Approved Centre (AC) status for IEG or partner institution, and submission of a Centre-Devised Assignment (CDA) for Aims C and D using the back-end semiconductor scenarios documented above.
