BTEC 매핑 갭 해소 현황 원본 매핑 문서의 6개 GAP이 시뮬레이터 설계에 통합된 방식

✓ GAP 1 — 산업 네트워크 프로토콜

SA-L1-04 (EtherCAT 비전센서 시뮬레이션) + SA-L2-01 (실물 신호 모니터링)으로 해소. Profinet 시뮬레이션 모듈 추가 예정.

✓ GAP 2 — 아날로그 I/O & PID 제어

MO-L1-02 (PID 게인 튜닝) + MO-L2-01 (Mold Press 실신호 취득)으로 해소. 온도 프로파일 비교 분석이 핵심 증거물.

✓ GAP 3 — SFC 소프트웨어 설계 도구

SA-L1-01 전용으로 SFC 설계 2-session 구성. Die Bond→Wire Bond→Mold→Eject 순서를 SFC로 설계 후 L2에서 검증.

✓ GAP 4 — 클린룸 패널 설계 제약

DB/WB/MO 공통 이론 1-session 삽입: ESD-safe 배선, 씰링 등급, 파티클 저감 설계. IEG 실물 클린룸 패널 케이스 스터디.

✓ GAP 5 — 개인 성과 자기평가 루브릭

L3 평가 시스템에 아랍어/영어 이중 언어 자기평가 양식 내장. 기술역량·시간관리·커뮤니케이션·산업준비도 4개 축.

✓ GAP 6 — BTEC 증거 형식화

L3 자동 리포트가 BTEC Aim A-D 기준에 맞는 I/O 리스트·테스트 매트릭스·관찰 기록지를 자동 생성. PDF 출력 지원.
