Core Logic: "Layer-by-Layer" Entry

Like a semiconductor deposition process, each phase adds a functional layer before the next begins. Tracks ③ + ⑤ are not preliminaries — they are revenue-generating deliverables in their own right, producing a Digital Walkthrough and a TTT Pilot that TAFE SA can immediately deploy. The relationship, credibility, and pilot data these produce are the necessary substrate on which the Track ① hardware proposal (Model C Cleanroom Package, targeting ALAT Phase 2–3 budget cycles) is then deposited.

Month 1 — Curriculum Localization

Meister High → English BTEC Mapping

  • Select 2–3 flagship IEG Meister-school curriculum units (PLC, Smart Factory, Pneumatics)
  • Translate learning objectives, NCS competency codes → English
  • Produce BTEC Unit 4039 / 4040 mapping table (NCS ↔ BTEC ↔ NQF Level 3–4)
  • Identify gaps requiring new assessment evidence for TAFE SA recognition
Month 2 — Digital Content Prototype

Semiconductor 8-Process Digital Walkthrough (VR/XR Concept)

  • Define 8 process stations: Wafer Prep → Oxidation → Photolithography → Etching → Doping → CVD → Metallisation → Testing
  • Script interactive narration for each station (EN/AR bilingual placeholders)
  • Produce 1 high-fidelity XR storyboard + UI wireframe per station (Unity-ready brief)
  • Package as "Digital Walkthrough Concept Deck" for TAFE SA review
